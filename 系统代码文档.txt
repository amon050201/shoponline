二、数据库表结构 (13张表)
================================================================================

users             - 用户(id,username,password_hash,email,phone,role_type,status)
category          - 商品分类(id,name,parent_id)
product           - 商品(id,name,price,stock,category_id,merchant_id,images,ai_tags)
cart              - 购物车(id,user_id,product_id,quantity,selected)
orders            - 订单(id,order_no,user_id,total_amount,status,payment_method)
order_item        - 订单项(id,order_id,product_id,price,quantity)
exchange_order    - 交换订单(id,order_no,initiator_id,receiver_id,status,ai_valuation)
address           - 收货地址(id,user_id,receiver_name,receiver_phone,region,detail_address)
favorite          - 收藏(id,user_id,product_id)
review            - 评价(id,user_id,product_id,rating,content)
coupon            - 优惠券(id,name,type,value,min_amount)
user_coupon       - 用户优惠券(id,user_id,coupon_id,status)
notification      - 通知(id,user_id,title,content,type,is_read)
banner            - 横幅(id,title,image_url)
search_history    - 搜索历史(id,user_id,keyword)
feedback          - 意见反馈(id,user_id,content,reply)
user_behavior     - 用户行为(id,user_id,product_id,action)
price_history     - 价格历史(id,product_id,price,recorded_at)
fraud_alert       - 欺诈告警(id,user_id,alert_type,risk_score)
exchange_valuation - AI估值缓存(id,product_id,ai_estimated_value)

三、核心API端点 (80+)
================================================================================

[认证] GET/POST /login, /register, /profile, /logout, /captcha
       POST /api/auth/login, /api/auth/register (JWT)

[商品] GET /product/list, /product/detail/{id}, /product/category/{id}
       GET /api/customer/products, /products/{id}, /products/search
       GET /api/customer/categories

[购物车] GET/POST/DELETE /cart/*
        GET/POST/DELETE /api/customer/cart/*

[订单] GET/POST /order/list, /order/detail/{id}, /order/confirm, /order/create
       POST /order/pay/{id}, /cancel/{id}, /ship/{id}, /receive/{id}
       GET/POST /api/customer/order, /order/{id}, /pay, /cancel, /receive
       POST /api/customer/order/refund/{id}

[地址] GET/POST /address/*
       GET/POST /api/customer/address/*

[以物易物] GET /exchange/market, /request/{id}, /my-orders
          POST /exchange/request, /confirm/{id}, /reject/{id}
          POST /exchange/cancel/{id}, /complete/{id}, /pay/{id}
          GET/POST/DELETE /api/exchange/orders, /products, /valuation, /stats

[商家] GET /merchant/dashboard, /product/add, /product/edit/{id}
       POST /merchant/product/add, /update
       GET/POST/DELETE /api/merchant/products, /product/add, /product/{id}

[管理] GET /admin/dashboard
       GET/POST/DELETE /api/admin/users, /users/{id}, /dashboard
       GET/POST /api/admin/fraud/alerts, /resolve/{id}

[AI]  POST /api/ai/valuation/evaluate, /evaluate-from-desc
      POST /api/ai/image/recognize, /image/search
      GET  /api/ai/price/predict/{id}, /price/history/{id}

[推荐] GET /api/recommend/personalized, /also-bought/{id}, /similar/{id}
       GET /api/recommend/trending, /new-products, /flash-sale
       POST /api/recommend/track

[其他] GET/POST /api/banners, /api/payment/*, /api/analytics/*
       GET/POST /api/customer/coupons, /favorites, /reviews
       GET/POST /api/customer/notifications, /search/history
       POST /api/customer/feedback, /api/upload/image

================================================================================
四、AI/ML 功能
================================================================================

1. AI智能估值: 通义千问LLM → 市场分析 + 建议, 统计回退(折旧系数0.85)
2. AI价格预测: 线性回归ML → 7/30/90天趋势, 每日2AM快照
3. AI欺诈检测: 5规则引擎 → 刷单/高取消率/自买自卖/价格异常/频繁交换
4. AI推荐: 协同过滤 → 买了又买 + 相似推荐 + 个性化
5. AI图像识别: 通义千问VL → 以图搜物
